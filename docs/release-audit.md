# 0.1.5 发布自查

本报告覆盖 0.1.5 源码与 Apple Silicon 原生 macOS 应用。源码准备公开；Developer ID 签名已完成，Apple 公证审核中，DMG 尚未公开分发。实际可下载文件以 GitHub Releases 为准。

## 安全修复

- 移除登录页面和服务端共用的固定 AES key / IV 与浏览器 CryptoJS 加密。远程控制台必须经 HTTPS；HTTP 仅允许真实回环来源及回环 Host。转发 TLS 标头仅信任显式配置的代理。
- 使用 PyCryptodome AES-GCM，随机 nonce、认证标签与文件身份校验；删除旧 CBC 与自研 padding。旧实现中文 padding 按字节处理，因此“按字符数”这一条是误报；缺少认证仍是实际问题。
- 原生应用使用 macOS Keychain 保存随机密钥。配置、账号初始化文件与 Telegram session 加密保存；session SQLite 在内存中运行。旧文件自动迁移，无法读取密钥或密文被篡改时停止并保留原文件。
- 命令行 / Docker 必须配置独立 TMD_SECRET_KEY。配置与 checkpoint 原子替换，0600 权限；拒绝符号链接和失去密钥后的明文覆盖。
- 默认监听 127.0.0.1。登录限流采用实际连接地址并加锁，密码使用 compare_digest，Flask session key 每次启动随机生成。
- cloudflared token 改用子进程环境，sing-box 配置改从标准输入传递；敏感值不会出现在命令行参数或临时节点 JSON 文件中。
- 应用与标准日志加入凭证脱敏，关闭异常局部变量输出。未知第三方输出仍需在分享前检查。
- 空访问密码禁止启动，新安装随机生成访问密码；没有硬编码默认登录密码。

## 稳定性与 UX

- API 默认最小间隔 1.2 秒，频道扫描并发 2，短 FloodWait 阈值 5 秒。worker 异常后重建，finally 保护空 node；快照先复制再遍历。
- 版本号集中于 utils/__init__.py，补全示例配置；Docker 将整个私有配置目录挂载以支持原子写入。
- 修复“仅文字”无法保存；原生与网页统一五步引导、GIF 动图、文件、未登录、已就绪、开始下载、保存位置与开始等文案。
- 账号切换与初次进入使用相同引导跳转逻辑；没有可展示媒体时显示“暂无图片或视频预览”。网页网络配置更改后必须重新测试成功才能继续。
- 实机打包检查发现并修复 ruamel 配置无法被 PyYAML 保存的启动问题；增加跨序列化器加密读写回归测试。

## 验证

- Python 3.11：184 项测试通过，无跳过；包括真实 sing-box 的配置、启动和停止。
- 认证加密 Unicode / 篡改 / 错误身份、原子写失败保护、密钥不可用保护、旧 session / WAL 迁移与重开、加密备份、HTTPS Cookie、伪造转发头、日志脱敏、worker 恢复、线程快照和仅文字偏好均有回归覆盖。
- 实际 macOS Keychain 组件随机密钥读写通过；仅操作隔离验证数据。
- Swift 6 原生编译及 Developer ID 正式签名、hardened runtime、深层严格签名检查通过。DMG 包装包含 Applications 入口。
- 最终冻结应用的空白冷启动、本地认证、仅文字保存与退出后重启持久化通过。
- 已通过 Xcode Direct Distribution 上传至 Apple 公证服务。审查尚在 Processing 时禁止声称已通过公证，禁止把未装订的包作为正式公开安装包。
- 源码包不携带 Git 历史、运行配置、登录 session、节点、数据库、日志、下载内容或证书私钥；交付前再次进行文件扫描与敏感值比对。

## 验证边界

真实 Telegram 登录、频道访问权限与下载速度仍取决于账号和网络，本轮回归不代表每个真实节点均可用。未在 Intel Mac、最低系统或干净的另一台 Mac 完成安装验收。Docker 未实机构建。

加密与当前文件路径绑定，迁移设备或路径需保留原钥匙串和路径。旧版明文备份不会自动删除，其他进程已经读过的明文无法追溯撤回。数据库、下载文件与日志不是全盘加密；设备本身应启用访问控制。自动漏洞扫描不能保证不存在未知风险。

Developer ID 正式签名会包含 Apple 证书公开的发布者名称与团队标识；这与源码中的账号凭证、手机号、服务器和节点信息不同。证书私钥不会打进安装包或源码。
