# 从第一次打开，到第一次下载

你只需要自己的 Telegram 账号、可访问 Telegram 的网络，以及一个保存文件夹。当前原生版本面向 macOS 14+ 的 Apple Silicon Mac。

## 安装：下载，拖入，打开

1. 打开 [0.1.5 下载页](https://github.com/designfuchen/telegram-media-downloader/releases/tag/v0.1.5)。
2. 下载 **Telegram-Downloader-0.1.5-arm64.dmg**。普通用户无需下载 source 源码包。
3. 双击 DMG，把 **Telegram Downloader** 拖到 **Applications（应用程序）**。
4. 等待拷贝结束，从“应用程序”打开它，再弹出安装磁盘。
5. 首次打开时，按 macOS 正常的确认提示继续。若提示签名或文件损坏，重新下载并通过 Issue 反馈；不要关闭系统安全检查。

应用已正式签名并通过 Apple 公证，票据附在应用上。DMG 是包装容器，未单独公证；备选应用 ZIP 见同一下载页。无需安装 Python、Docker 或运行终端命令。

## 1. 申请 API 凭证

这是 Telegram 为应用连接提供的 `API ID` 与 `API Hash`，不是频道 ID，也不是代理 UUID。

1. 先在 Telegram 官方客户端注册并正常登录自己的账号。
2. 打开 [my.telegram.org/apps](https://my.telegram.org/apps)。输入手机号，带国际区号。
3. 按网页提示查看 Telegram 官方消息，输入该网站的登录验证码。
4. 进入 **API development tools**。已有应用时，直接查看 App configuration。
5. 如果显示创建表单，填写自己的应用信息：

| 英文项目 | 怎么填 |
| --- | --- |
| App title | 自己能识别的应用名称，例如 `My Archive` |
| Short name | 5–32 位字母与数字，例如 `myarchive2026` |
| URL | 按当前表单要求填写；没有自己的网址时，不要编造他人的网站 |
| Platform | 选择与用途相符的平台，例如 Desktop |
| Description | 简短说明用途，例如个人频道内容归档 |

6. 创建后复制 **App api_id**（数字）与 **App api_hash**（一串字符）。回到下载器“API 凭证”，填入并保存。

申请流程与当前要求以 [Telegram 官方说明](https://core.telegram.org/api/obtaining_api_id) 和实际表单为准。每个手机号目前只能关联一个 API ID；已有凭证无需重复创建。若网页报错，确认账号与表单信息，避免反复快速提交。

## 2. 配置并测试网络

你的 Mac 已能直接访问 Telegram，可以先选“直接连接”；否则导入自己正在使用的节点。

统一入口可以粘贴节点分享链接，或导入 YAML / JSON 文件，识别后选择一个节点。常见格式包括 SS、VLESS、VMess、Trojan、Hysteria2、TUIC、SOCKS5 与 HTTP / HTTPS；Clash / Mihomo 和 Base64 链接列表也可识别。协议名称相同不代表所有扩展都兼容，具体参数见 [节点导入范围](configuration.md#统一节点导入)。

**粘贴完整分享链接。** 单独一串 UUID 不包含服务器、端口和传输参数，不能作为节点导入。分享链接通常需要在你的代理客户端节点菜单中复制；入口位置取决于所用客户端。

点击“保存并测试连接”，等待结果。测试成功后才进入下一步。修改节点或连接方式后重新测试。远程订阅不会自动拉取；不要把自己的订阅、节点密码或 UUID 发到公开 Issue。

## 3. 登录 Telegram

1. 填写手机号，包含国际区号。
2. 点击发送验证码，等待指示消失。
3. 优先查看 Telegram 客户端中来自 Telegram 的官方消息；验证码的实际送达方式由 Telegram 决定。
4. 输入验证码并继续。开启两步验证时，再填写自己设置的两步验证密码。
5. 登录成功后继续添加频道。

没有收到时，等待页面显示可重新发送，再点击“重新发送验证码”。遇到 Telegram 要求等待的提示，按提示等候；快速反复发送通常不能解决问题。验证码和两步验证密码不写入配置文件；登录会话保存在本机加密存储中。

## 4. 添加频道

### 公开频道：直接粘贴链接

打开频道资料，复制链接，粘贴进下载器即可。也可使用用户名，例如 `@example_channel`。这里的示例不是内置下载来源，请替换为自己的频道。

### 已加入的私密频道：使用频道 ID

先确认下载器登录的账号已经加入且能查看该频道。邀请链接和频道 ID 是两回事，工具不会自动加入私人频道。

如果 Telegram 客户端允许复制某条消息的链接，例如：

```text
https://t.me/c/1234567890/42
```

`1234567890` 是该链接中的频道数字，`42` 是消息编号。对于这一示例，可在下载器中使用 `-1001234567890`。不要把末尾的消息编号当作频道 ID。链接语法见 [Telegram 消息链接说明](https://core.telegram.org/api/links#message-links)，ID 转换见 [Telegram ID 说明](https://core.telegram.org/api/peer-ids)。

部分频道不允许复制或转发，某些客户端也不会显示该入口。这种情况下不要假设一定能通过链接取得 ID。

### 使用 ID 查询机器人（可选）

你也可以寻找提供频道 ID 查询的机器人，例如 [@username_to_id_bot](https://t.me/username_to_id_bot)。进入机器人后点击 Start，先阅读它当前的帮助，按它支持的方式提交公开用户名或频道信息。

机器人支持的命令、转发识别与私密频道查询能力可能变化。它无法因此获得你所有私人频道的访问权；不要发送验证码、API Hash、节点信息，也不要为查询而转发私人内容。公开频道通常直接用链接即可，省去查询 ID 这一步。

添加后看到频道卡片，说明来源已经登记。**添加频道不等于已开始下载**；下一步选好保存位置，再点击开始。

## 5. 选择保存位置并开始

点击“选择保存文件夹”，使用 macOS 系统窗口选择这台 Mac 的目录、外置磁盘或已挂载的网络磁盘。无需 NAS。

打开“设置 → 下载内容”，按需选择图片、视频、音频、文件、语音、圆形视频、GIF 动图或文字。只选文字也可以保存。在“文件整理”选择按频道和年月分类；在“保存位置”可以随时更换目录。

点击“开始下载”，到“频道与下载”查看状态。首次扫描可能需要一段时间；发现任务后显示传输进度和已完成数量。图片与视频在下载完成后生成本地预览；纯音频或文件频道没有图片预览是正常情况。

更换目录无需重新登录。新任务使用新目录，已有任务继续保存到原位置。可以暂停单个频道或暂停全部，之后点击“开始下载”继续。

## 一次导入很多频道

1. 打开“批量导入”，下载 [CSV 模板](templates/channels.csv)。
2. 保留第一行表头，把示例频道替换为自己的来源。
3. 上传 CSV，查看识别、重复和访问权限结果。
4. 确认需要的频道，再导入频道库。
5. 选好保存位置并开始下载。

完整字段说明见 [频道导入文档](channel-import.md)。私人 CSV 不要上传到公开仓库。

## 遇到问题，按这个顺序检查

| 现象 | 先做什么 |
| --- | --- |
| 网络测试失败 | 确认完整节点信息与当前网络，再测试；不要仅凭代理客户端的“已连接”判断 |
| 添加 ID 后找不到频道 | 确认当前登录账号已加入、ID 没带消息编号；公开频道改用链接 |
| 一直没有下载 | 查看是否已点击开始、是否暂停、扫描提示与频道访问权限 |
| 保存位置不可用 | 重新选可写文件夹；外置磁盘确认已挂载且空间足够 |
| 修改设置后没有影响旧任务 | 下载偏好用于后续扫描与新任务，已排队任务和已有文件会保留 |
| 没有缩略图 | 音频、文件、文字没有图片预览；图片 / 视频需先完成下载 |
| 切换账号后任务暂停 | 切换会保存并暂停原账号任务；切回后点击开始下载 |

仍无法解决，请使用 [Bug 模板](https://github.com/designfuchen/telegram-media-downloader/issues/new?template=bug_report.yml)，写清版本、使用方式、操作步骤和结果，附脱敏截图。漏洞与凭证泄漏使用 [私密安全报告](../SECURITY.md)。
