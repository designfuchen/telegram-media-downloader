01

API 凭证

在 Telegram 官方页面 创建应用，复制 API ID 和 API Hash。只需设置一次。

没有这两项信息？照着下面做，只需要申请一次。
  1. 打开 Telegram 官方申请页 ↗，填写你的 Telegram 手机号。登录码通常发到 Telegram 应用内，请查看官方消息。
  2. 进入 API development tools。若已有应用，直接复制信息；没有则创建一个。
  3. App title 填自选名称，如 My Downloader；Short name 填字母和数字，如 mydownloader2026；Platform 选 Desktop。按页面要求填写其余项目后，点击 Create application。
  4. 把 App api_id 复制到上面的第一格，把 App api_hash 复制到第二格，再点下一步。

申请失败时，先确认是已注册的 Telegram 账号，并按官网错误提示处理。下载器不能替你绕过 Telegram 的申请限制。

02

网络连接

选一种能访问 Telegram 的方式。不确定时，先测试直接连接。

网络连接
带上你的节点，就能开始

粘贴分享链接，或上传配置文件。我们会自动识别格式，你只需选一个节点。

SSVLESSVMessTrojanHysteria2TUICSOCKS5HTTP
一个入口，自动识别多种格式。粘贴或上传 → 选择节点 → 测试并保存。
这个统一入口支持哪些格式？

导入格式：单个分享链接、每行一个的多节点链接列表、Base64 链接列表，以及 Clash / Mihomo 格式的 YAML（.yaml / .yml）或 JSON 配置。最多 256 KB、500 个节点。

节点协议：SS、VLESS、VMess、Trojan、Hysteria2（hy2）、TUIC、SOCKS5 和 HTTP / HTTPS 代理。VLESS、VMess、Trojan 支持 TCP、WebSocket 和 gRPC；VLESS REALITY 支持 TCP / Vision。

读取范围：只读取节点，不导入分流规则、DNS 或远程订阅。原始内容只提交到你自己的下载器服务，保存时只保留选中的节点。不兼容的协议、插件或附加设置会逐项提示。

读取不会保存设置，也不会连接任何节点。

部分节点暂不兼容
    找不到分享链接或配置文件？

    在小火箭等代理客户端中，打开节点的分享菜单，选择「复制链接」。节点类型是 VLESS，就复制 vless:// 链接，不必寻找 SS。

    使用 Clash / Mihomo 时，可以导出包含 proxies 的 YAML 配置。截图、IP 或 UUID 单独无法还原完整连接。

    特殊插件、XHTTP 等暂不兼容的设置，可在已有代理软件中连接，然后选择「其他代理」填写它的 SOCKS5 地址。

    代理和下载器在不同设备上？

    填写代理所在电脑的局域网 IP，并在代理软件中允许局域网连接。127.0.0.1 只适用于代理与下载器在同一台设备。

    测试不会保存设置，也不会中断已有下载。
