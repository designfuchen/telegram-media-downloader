# 使用体验与验证范围

首次使用按照四步引导：申请 API → 网络与 Telegram 登录 → 添加频道 → 确认目录并开始。

- 保存配置不等于登录成功。只有真实 Telegram 客户端启动后，控制台才允许开始下载。
- 首次账号登录在网页输入手机号、验证码和可选两步验证密码；后续复用本机会话。
- 演示模式不连接 Telegram，启动请求会被拒绝，不会显示虚假的传输状态。
- 本机可选择 Mac 文件夹；远程部署填写服务所在设备的路径。
- 网络导入支持分享链接、Clash / Mihomo YAML / JSON、Base64 链接列表，识别后选择一个节点再测试保存。
- 频道和邀请链接分别提供 CSV 模板，导入先预览、去重和校验。
- 频道未加入、API 错误、网络不可达等仍需按具体错误处理。导入成功不代表所有内容都能访问。
- 提供键盘焦点、文字错误提示和减少动态效果选项；未完成全面屏幕阅读器认证。

自动化回归测试使用隔离数据库和模拟 Telegram 客户端，不使用个人凭据。源码包发布检查及已知限制见 [发布自查](release-audit.md)。
