# 原生界面自查（2026-09-30）

采用 SwiftUI Pro、Motion Design、Apple HIG review 的设计与代码检查方法。

- 原生 NavigationSplitView 侧栏、系统字体、SF Symbols、系统菜单、文件选择/保存面板。
- 中性色背景与单一靛蓝强调色；浅色、深色、跟随系统；不使用外部字体或运行时 CDN。
- 首次引导一次展示一个任务；API 教程可展开；未登录或没有频道时禁用下载并解释原因。
- 状态由真实引擎返回；无效节点明确显示错误，不把零文件显示为下载成功。
- 敏感输入用 SecureField；验证码/密码提交后清空；不在界面回显已保存的 API Hash。
- 原生按钮保留文字辅助功能标签；支持键盘；动效约 200–250 ms，尊重 Reduce Motion。
- 按页读取 50 个频道，避免一次渲染整库；网络请求使用异步 URLSession。

## 0.1.2 频道反馈与目录设置修正

- 添加频道后立即清理列表缓存，并从权威频道库读取总数；新增测试覆盖原先缓存为空与重复添加。
- 当前步骤内显示请求等待转圈、操作说明和成功/失败消息；连接 Telegram 和完成登录也显示等待状态。
- 目录选择使用独立接口验证可写性并更新运行时保存路径，不修改 API、网络或登录会话，不要求重连。已有任务仍保留原目标，新任务使用新路径。
- 已登录状态独立于重连要求；需要重连时仍禁止开始下载，避免将其错误描述为退出登录。
- 153 项 Python 回归通过；Swift 6 编译通过。此次未操作真实验证码，也未替用户关闭现有应用。

## 0.1.3 独立设置与真实内容预览

设置与首次引导分离：下载内容、文件整理、保存位置、账号与网络四类。提供图片、视频、音频、文档、语音、圆形视频、动画多选，纯文字开关，视频/音频/文档扩展名筛选，文件夹分类、文件名组成和并发数量。

媒体与命名偏好更新运行时配置，对后续扫描和新任务生效；已排队任务不追溯清除。并发数量变更需要重连，登录状态不因此显示为退出。

频道卡片显示最多三张本地已完成文件的缩略图；支持常见图片与 MP4/MOV/M4V 视频静态首帧。没有可用内容时显示占位。预览不上传、不读取当前保存目录之外的文件、不跟随越界符号链接，不额外访问 Telegram。显示真实当前文件进度、速度、已传输大小与预计时间。

验证：156 项 Python 测试通过；Swift 6 编译通过；缩略图降采样与路径边界测试通过。独立空白配置的应用启动成功，但原生界面控制连接随后中断，设置页的完整点击验收尚未完成。

## 0.1.4 账号管理与界面整理

- 设置重新组织为下载内容、文件整理、保存位置、网络和账号。统一页标题、卡片宽度、内边距和浅分隔线。媒体类型改为图标、简短说明与勾选组成的网格。
- 账号页显示当前账号与登录状态，提供退出登录、添加账号和切换账号。后两者也可从窗口右上角进入。确认前解释暂停下载和会话/记录保留。
- 旧版数据保留在原目录，不搬移也不清空。新账号独立保存登录会话、任务数据库、频道、控制台凭证；只带入 API、网络和下载偏好，新账号默认暂停并使用独立输出子目录。
- 切换先持久化暂停状态，停止旧引擎后再开启新账号。退出先取消下载与连接监控任务，再通过 Telegram 注销本机会话。失败时保留记录并提示重试。
- 永久设置页去除“前两步”“下一步”的引导用语。首次设置仍按任务逐步展开；成功登录后可跳过已完成步骤。
- 过渡保持约 180–250 ms，系统 Reduce Motion 开启时禁用位移与显式切换动画。支持浅色与深色。
