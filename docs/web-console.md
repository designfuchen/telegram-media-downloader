# Web 界面

首页与原 `/batch` 页面整合到同一个控制台的“频道导入”页签。旧 `/batch` 地址会跳转到 `/?view=imports`。可在同一页签打开文本 / CSV 导入，或处理手动加入频道的固定批次。

界面资源全部随源码发行，位于 `module/templates/` 与 `module/static/`。

| 区域 | 用途 |
| --- | --- |
| 顶部控制栏 | 全局暂停与继续、运行状态、可选代理节点管理 |
| 频道概览 | 频道数量、下载状态、速率和进度 |
| 频道库 | 查找、分组、优先级、添加、编辑和单频道控制 |
| 导入中心 | 文本 / CSV 解析、去重、权限校验及确认 |
| 频道详情 | 文件明细、已完成与进行中的文件 |
| 配置界面 | 媒体类型、命名、路径、并发及连接设置 |

全局暂停影响全部传输；单频道暂停仅影响该频道。全局暂停时启动一个频道，只启动选中的频道。频道进度包含已完成字节和当前传输进度。

代理节点切换针对可选的独立 sing-box 容器，需要自己的代理配置和 Docker 套接字授权。默认 Compose 不提供这两项；未配置时界面会提示不可用，不影响普通下载。

发布内容没有用户的真实截图、频道清单或任务数据。若为仓库补充截图，请使用虚构示例和独立演示数据库。
